# LLM.AI

A local-first AI software engineering assistant.

## Features

- Chat with local LLMs (Ollama)
- Explain source files
- Ask questions about code
- Create files from prompts
- Improve and refactor code
- Execute terminal commands
- Analyze projects
- Run builds and debug issues
- Semantic memory search

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate

pip install -r requirements.txt
```
